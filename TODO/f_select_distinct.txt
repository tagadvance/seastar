CURRENT STATE:
When raw.parameters.isDistinct is set, SelectHandler logs "DISTINCT is not supported, ignoring"
and returns all rows, silently producing incorrect results.

WHAT REAL CASSANDRA DOES:
SELECT DISTINCT returns distinct partition keys. It is only valid when the selection is
restricted to partition-key columns (and static columns); selecting a non-partition-key column
with DISTINCT is an InvalidQueryException.

IMPLEMENTATION PLAN:
1. When isDistinct, validate that every selected column is a partition-key or static column;
   otherwise throw InvalidQueryException matching Cassandra's message.
2. De-duplicate the result rows by partition key before building the AsyncResultSet.
3. Remove the warn-and-ignore fallback.

DEPENDENCIES: none.
